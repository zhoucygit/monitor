要确认 Kubernetes 中的组件是否暴露到集群外部可访问，可以从以下几个层面排查：

✅ 一、确认组件是否部署
以 kube-state-metrics 为例：

bash
复制
编辑
kubectl get pods -A | grep kube-state-metrics
如果组件未部署，需先部署。

✅ 二、确认组件是否暴露了端口（Service / HostPort / NodePort / Ingress）
以 node-exporter 为例：

bash
复制
编辑
kubectl get svc -A | grep node-exporter
你可能看到如下输出：

text
复制
编辑
monitoring   node-exporter   ClusterIP   10.96.0.10   <none>   9100/TCP
表示未暴露到集群外部。

✅ 三、如何暴露组件到集群外部
方案 1：使用 NodePort 暴露（推荐用于测试环境）
以 kube-state-metrics 为例：

bash
复制
编辑
kubectl -n kube-system expose deployment kube-state-metrics --type=NodePort --port=8080 --name=kube-state-metrics-np
然后查看暴露端口：

bash
复制
编辑
kubectl -n kube-system get svc kube-state-metrics-np
假设输出：

text
复制
编辑
kube-state-metrics-np   NodePort   10.96.0.12   <none>   8080:32080/TCP
则你可从任意 Node 节点（例如 10.100.12.11）访问：

cpp
复制
编辑
http://10.100.12.11:32080
方案 2：使用 HostPort 绑定宿主机端口（对 kubelet/cAdvisor 常见）
确认 Pod 的 yaml 中是否设置了 HostPort：

yaml
复制
编辑
ports:
  - containerPort: 4194
    hostPort: 4194
    protocol: TCP
如果未设置，可修改 Deployment 或 DaemonSet 资源增加 hostPort 字段。

方案 3：使用 Ingress 暴露 HTTP 接口
（一般用于有 ingress-nginx 控制器的情况，不推荐专为 Prometheus 裸暴露 HTTP 时使用）
